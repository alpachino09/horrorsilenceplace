# Свой хищник: подготовка Unity

Сначала запустите `Tools/OwnPredator/create_predator.py` в Blender.
Из созданной папки на Рабочем столе скопируйте всю
`Assets/Creatures/SilencePredator` в папку `Assets/Creatures` Unity-проекта.
В этом checkout находятся исходники подготовки, без сгенерированных FBX и 4K-карт.

После импорта: **SILENCE → 17 Create Original Predator Demo**.
Команда предназначена создать prefab, Animator и отдельную демонстрационную сцену.
В облаке Unity Editor отсутствует: компиляция API, импорт Generic Rig и выполнение
этой команды не проверены. Готовые `.prefab` и `.unity` пока не созданы.

Контроллер управляет только внешностью; игровой ИИ, слух, урон и сетевое движение
остаются в прежних системах. Подключение к существующему хищнику — отдельный шаг.
Художественный результат является первым проходом и не принят как AAA-финал.

Полная инструкция: `Docs/OwnPredator/README_RU.md`.
