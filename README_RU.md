# SILENCE — установка и прежний прототип

**Текущий игровой блок 0.3.0:** [новая кампания и проверки](Docs/GAMEPLAY_RU.md).
Инструкция ниже описывает первую установку и сохранённый прототип Sprint01.

**Обновление уже установленной фермы:** следуй [короткой инструкции](README.md).
Она обновляет исходники с сохранением `.meta` и созданных сцен. Сетевой модуль подключается
отдельно через меню 03; [проверка Sprint 02](Docs/SPRINT02_RU.md) содержит точные версии,
сборки Host/Client и тесты 1/2/4 процессов. Новый кооператив в Unity ещё не проверен.

Это пакет C#-исходников и генератор Unity-сцен. Владелец подтвердил первый запуск фермы,
управление и двери в Unity 6.6; автоматические тесты Unity и остальная приёмка ещё ожидаются.
В исходном Git-репозитории не было проекта: здесь намеренно нет выдуманных `ProjectVersion.txt`,
`Packages/manifest.json` и сцен, якобы сохранённых редактором. Сцены, материалы, настройки и префаб
создаст **Unity Editor**, когда будет выполнена команда меню.

## Установка на Mac

1. В Unity Hub создай проект **Unity 6 → Universal 3D (URP)**. Если такой проект уже есть, используй его.
   Дождись завершения первого импорта. Точную установленную версию не меняй ради этого пакета.
2. Открой **Window → Package Manager → Unity Registry**. Установи **Input System**
   (`com.unity.inputsystem`) и **Test Framework** (`com.unity.test-framework`) в совместимых версиях,
   которые предлагает именно твой Editor. URP уже входит в шаблон Universal 3D.
3. В **Edit → Project Settings → Player → Other Settings → Active Input Handling** выбери
   **Input System Package (New)** или **Both**. Подтверди перезапуск Editor, если он требуется.
4. Скопируй `Assets/_Silence` из этого пакета внутрь `Assets` своего Unity-проекта,
   а `Docs` — в корень проекта. Не заменяй свои одноимённые файлы без сравнения.
   При первом импорте Unity сама создаст `.meta`; затем их нужно хранить вместе с ассетами.
5. Дождись компиляции. При красных ошибках не продолжай генерацию: скопируй первую ошибку из Console.
6. В верхнем меню нажми **SILENCE → 01 Generate Farm Prototype**.
   Результат появится в `Assets/_Silence/Generated/Sprint01/`:
   `Bootstrap.unity`, `Farm_Prototype.unity`, `Player.prefab`, материалы и ScriptableObject-настройки.
7. Выполни **SILENCE → 02 Validate Prototype**. Фактическая версия Unity, версии пакетов
   и результаты проверки будут записаны в `Library/Silence/Validation.txt`.
8. Дважды щёлкни `Bootstrap.unity`, сохрани текущую сцену при необходимости и нажми **Play**.
   В окне Game нажми **Продолжить**. Начальная сцена загрузит ферму.

Генератор не очищает открытую пользовательскую сцену. Он создаёт свои сцены аддитивно и закрывает
только их. Повторная генерация сохраняет существующий результат без перезаписи. Если генерация
прервалась, сохрани полученные файлы, переименовав каталог `Sprint01` через окно Project, затем повтори.
Существующие записи Build Settings сохраняются; две сцены прототипа добавляются в список.
В Unity 6 Build Profiles при включённом собственном списке сцен профиля убедись, что обе сцены
включены в активный профиль; для сборки запускай `Bootstrap` первой сценой.

Ранее выданный отдельный `SilencePlayerController` к новому Player добавлять не нужно:
здесь движение, камера и взаимодействие разнесены по компонентам.

## Управление

| Действие | Клавиатура/мышь | Геймпад |
|---|---|---|
| Движение | WASD | Левый стик |
| Обзор | Мышь | Правый стик |
| Бег | Удерживать Shift | Удерживать нажатие левого стика |
| Присесть | Удерживать Ctrl | Удерживать нажатие правого стика |
| Прыжок | Space | Нижняя кнопка |
| Взаимодействовать | E | Левая кнопка |
| Фонарь | F | D-pad вверх |
| Инвентарь | Tab | Верхняя кнопка |
| Меню/возврат | Esc | Start |

Полного управления меню геймпадом и переназначения клавиш в UI пока нет.
Привязки можно редактировать в `Assets/_Silence/Settings/SilenceControls.inputactions`.

## Быстрая проверка

Выйди со спавна по дорожке. Дом слева, сарай справа впереди, выходные ворота прямо у дальней
ограды. В доме есть лестница и два предмета; в сарае ещё два. Можно подобрать только три.
Под навесом справа от спавна проверь, что приседание позволяет пройти, а вставание под крышей
блокируется. Наведись на дверь, радио, предмет или ворота с расстояния не более 2.5 м: появится
подсказка взаимодействия. Постоянного прицела нет. Открой ворота, пройди к табличке за ними
и взаимодействуй с ней, чтобы завершить маршрут прототипа.

Подробные проверки: [Docs/MANUAL_TESTS_RU.md](Docs/MANUAL_TESTS_RU.md).
Фактические результаты: [Docs/IMPLEMENTATION_STATUS.md](Docs/IMPLEMENTATION_STATUS.md).

## Проверки без Unity

Для них отдельно нужен .NET 8 SDK; самой игре этот SDK не нужен.

```sh
dotnet restore Tools/CoreTests/Silence.CoreTests.csproj --locked-mode
dotnet test Tools/CoreTests/Silence.CoreTests.csproj --no-restore --logger trx --results-directory TestResults/Core
dotnet run --project Tools/SourceChecks/SourceChecks.csproj -- Assets
```

Первый запуск собирает **чистое C#-ядро** и выполняет те же NUnit-тесты, что лежат в EditMode.
Последняя команда проверяет синтаксис C# 9 всех файлов в `Assets`, но не связывает Unity API.
Ни одна из этих команд не заменяет компиляцию, генерацию сцен и PlayMode в Unity.

Сетевой транспорт, Host/Client, монстр, микрофон, голос, сохранения кампании и полноценная физическая
переноска предметов ещё не реализованы. Двери сейчас переключаются кнопкой; радио включает только
индикатор. Подробности следующего сетевого этапа: [Docs/NETWORKING_PLAN.md](Docs/NETWORKING_PLAN.md).
