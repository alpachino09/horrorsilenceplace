# Исправление сцены просмотра — 0.3.3

Ошибка `Cannot create a new scene additively with an untitled scene unsaved`
из CreateDemo возникала из-за самого инструмента: Prepare уже открыл безымянную
временную сцену, а CreateDemo пытался открыть ещё одну additive-сцену.
Сохранение исходной игровой сцены не устраняло эту внутреннюю последовательность.

Теперь инструмент использует одну временную сцену: сохраняет art-prefab,
удаляет только временный экземпляр, создаёт просмотр в этой же сцене и сохраняет
его как HoodedGirl_Demo.unity. Единый внешний finally закрывает рабочую сцену
и возвращает активность исходной. Игровая сцена не пересоздаётся и не сохраняется
по другому пути. Лишний временный экземпляр персонажа в просмотр не попадает.

Обновление: `Downloads/SILENCE_HoodedGirl_AutoFix_0.3.3.zip` → распаковать →
пункт 00 → выбрать папку SILENCE_HoodedGirl_AutoFix_0.3.3 с Assets/LocalPackages →
дождаться компиляции → Clear → 22 → после успеха 23.
Пакет восстанавливает полный файл; предыдущие ручные исправления не требуются.

151 существующий тест чистого C# пройден; это не тест сцены Unity.
Проверены синтаксис в пяти конфигурациях, содержимое архива и структура вызовов:
один NewScene, отсутствие нового NewScene/CloseScene в CreateDemo, передача
рабочей сцены, её сохранение и очистка в наружном finally.
Unity Editor в облаке отсутствует: фактическое создание/сохранение/просмотр сцены
и Play нужно подтвердить в Unity владельца.
