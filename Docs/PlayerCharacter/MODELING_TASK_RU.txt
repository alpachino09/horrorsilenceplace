Твоя задача — создать в Blender высокодетализированную 3D-модель женского персонажа для моей игры на Unity.

Я прикрепил 3 референсных изображения. Используй их как главный визуальный ориентир.

ВАЖНО:
Мне нужен только персонаж.
Без арбалета.
Без колчана.
Без стрел.
Без дополнительного оружия.
Нужно смоделировать только саму девушку, её лицо, волосы, капюшон, одежду, тело, обувь, перчатки и лицевые blendshape.

Главная цель — сделать персонажа максимально похожим на референсы по:
- лицу
- форме головы
- глазам
- губам
- носу
- бровям
- волосам
- капюшону
- одежде
- пропорциям тела
- общей стилистике материалов

Но при этом работай как с полноценной 3D-моделью для игры, а не как с концепт-картинкой.

-----------------------------------
2. ЦЕЛЬ
-----------------------------------

Создай полноценную игровую 3D-модель женского персонажа в Blender для последующего импорта в Unity.

Нужен не грубый прототип, а качественный персонаж со следующими характеристиками:

- реалистичное лицо
- реалистичные пропорции взрослой девушки
- hood / капюшон
- многослойная ткань на шее
- облегающая тактическая одежда
- карго-брюки
- карманы и швы
- перчатки
- обувь
- материалы, похожие на референс
- blendshape для лица
- игровая пригодность для Unity

-----------------------------------
3. АНАЛИЗ РЕФЕРЕНСОВ
-----------------------------------

Используй все 3 изображения.

Референс 1:
Крупный план лица.
Использовать для:
- формы лица
- глаз
- век
- губ
- носа
- бровей
- кожи
- общего сходства лица
- формы капюшона вокруг лица
- прядей волос

Референс 2:
Полноразмерные виды персонажа.
Использовать для:
- пропорций тела
- одежды
- формы капюшона
- строения штанов
- ремней
- швов
- карманов
- обуви
- перчаток
- силуэта персонажа

Референс 3:
Мимика / blendshapes.
Использовать для:
- выражений лица
- деформации глаз
- деформации рта
- деформации бровей
- подготовки лицевых shape keys / blendshapes

Сначала создай краткий файл:
reference_analysis.md

Туда запиши:
- основные визуальные особенности лица
- особенности одежды
- особенности силуэта
- какие элементы видны точно
- какие элементы нужно реконструировать по логике

-----------------------------------
4. ЛИЦО
-----------------------------------

Лицо — самый важный элемент.

Нужно максимально приблизить модель к референсу.

Характеристики:
- молодая взрослая женщина
- светлая кожа
- серо-зелёные глаза
- тёмные волосы
- естественные плотные брови
- мягкий подбородок
- аккуратный нос
- естественные губы
- реалистичные веки
- не мультяшный стиль

Нельзя:
- аниме-стиль
- чрезмерно большие глаза
- кукольная внешность
- упрощённый low poly вид
- грубую стандартную голову без доработки

Нужна хорошая топология для:
- глаз
- рта
- носогубной области
- щёк
- бровей
- челюсти

-----------------------------------
5. ВОЛОСЫ И КАПЮШОН
-----------------------------------

Капюшон должен быть похож на референс:
- оливково-серый оттенок
- мягкая плотная ткань
- выраженные складки
- аккуратная форма вокруг лица
- реалистичная толщина материала
- швы и края
- внутренняя и внешняя поверхность

Волосы:
- тёмные
- прямые
- частично скрыты капюшоном
- несколько прядей спереди
- без пластиковой массы
- можно сделать через hair cards или оптимизированные геометрические пряди

-----------------------------------
6. ТЕЛО И ПРОПОРЦИИ
-----------------------------------

Персонаж должен иметь естественные взрослые женские пропорции.

Ориентир по росту:
примерно 170–175 см в масштабе Unity.

Нужно воссоздать:
- стройную фигуру
- естественные пропорции рук и ног
- адекватную ширину плеч
- правильную посадку одежды
- реалистичный силуэт

-----------------------------------
7. ОДЕЖДА
-----------------------------------

Смоделируй одежду максимально близко к референсам.

Нужны:
- верхняя тактическая одежда / куртка с капюшоном
- многослойная ткань / шарф вокруг шеи
- облегающий верх
- длинные рукава
- швы
- складки ткани
- карго-брюки
- боковые карманы
- усиленные зоны на коленях
- перчатки
- обувь

Важно:
одежда не должна быть просто нарисована текстурой на теле.
Основные формы одежды должны быть геометрически смоделированы.

-----------------------------------
8. МАТЕРИАЛЫ И ТЕКСТУРЫ
-----------------------------------

Создай PBR-материалы для:
- кожи
- волос
- ткани
- одежды
- перчаток
- обуви

Материалы должны выглядеть реалистично:
- кожа не пластиковая
- ткань матовая
- швы читаемые
- разные ткани должны отличаться по roughness
- мягкий микрорельеф
- аккуратный normal map при необходимости

Ориентир по качеству:
2K / 4K текстуры там, где это оправдано.

Если какие-то материалы не получится сделать полностью процедурно на хорошем уровне, зафиксируй это в отчёте, но не подменяй всё грубым шумом.

-----------------------------------
9. ГЕОМЕТРИЯ
-----------------------------------

Финальная модель должна быть пригодной для игры.

Требования:
- чистая топология
- нормальная UV-развёртка
- корректные нормали
- отсутствие явных самопересечений
- понятные названия объектов
- отдельные материалы по частям
- возможность экспорта в Unity

Не оставляй модель в виде грубого набора сфер, кубов и цилиндров.
Примитивы допустимы только на этапе блокинга.

-----------------------------------
10. РИГ
-----------------------------------

Создай рабочий риг под Unity.

Требования:
- humanoid-совместимая структура по возможности
- кости рук
- кости ног
- позвоночник
- шея
- голова
- пальцы рук
- базовый лицевой риг через blendshape

Модель должна быть пригодна для:
- idle
- walk
- run
- turn
- look around
- facial animation

-----------------------------------
11. BLENDSHAPES / SHAPE KEYS
-----------------------------------

Нужно создать 52 ARKit blendshapes или максимально близкий эквивалент для Unity.

Важно:
- не создавать пустые shape keys
- не делать одинаковые shape keys
- каждая shape key должна реально менять лицо
- ориентироваться на 3-й референс

Обязательно создать демонстрационные выражения:
- neutral
- blink
- mouth open
- fear
- pain
- surprise
- tension

-----------------------------------
12. UNITY
-----------------------------------

Финальная цель — использовать персонажа в Unity.

Подготовь:
- .blend исходник
- экспортируемый .fbx
- текстуры
- материалы
- краткую документацию

Создай понятную структуру папок, например:

Assets/
  Characters/
    HoodedGirl/
      References/
      Models/
      Textures/
      Materials/
      Rigs/
      Blendshapes/
      Exports/
      Documentation/

Если работаешь вне Unity-проекта, всё равно соблюдай похожую структуру.
