# Исправление меню 22 — 0.3.1

Ошибка `Expected the prepared Humanoid hierarchy` возникала при прямом
сравнении имён FBX с метками HumanTrait, содержащими пробелы. Новое сопоставление
удаляет пробелы только при поиске кости, а humanName сохраняет точно из Unity API.
Сначала загружается полная Generic / NoAvatar иерархия без оптимизации костей,
затем строится и проверяется Humanoid Avatar. Проверка отсутствующих/дублирующихся
костей сохранена и теперь выдаёт конкретные имена вместо порога <50.

Для уже установленной модели достаточно заменить один файл:
`Assets/Characters/HoodedGirl/Editor/HoodedGirlPreparation.cs`.
Маленький архив: `Downloads/HoodedGirl_ImportFix_0.3.1.zip`, инструкция внутри.
После компиляции выполнить 22, затем при успехе 23. Повторять скачивание FBX
и текстур или менять версию Unity не требуется.

151 тест .NET пройден, включая 10 регрессионных проверок реального C# resolver.
Имена сверены с повторным импортом трёх поставленных FBX, по 56 костей
(55 Humanoid + Root). Полный native import/API binding/Play в Unity здесь
не выполнялся; для подтверждения нужен успешный запуск 22 на компьютере владельца.
