# Контракт анимации главного персонажа

Модель и реальные клипы ещё ожидают референсы/исходники. Этот контракт описывает
написанный драйвер; наличие параметров само по себе не создаёт анимацию.

| Параметр | Тип | Значение |
|---|---|---|
| MoveX | float | Сглаженная скорость вправо, м/с; влево отрицательная |
| MoveZ | float | Сглаженная скорость вперёд, м/с; назад отрицательная |
| Speed | float | Горизонтальная скорость, м/с |
| VerticalSpeed | float | Вертикальная скорость, м/с; падение отрицательное |
| LookPitch | float | Угол камеры по X: от −85 до +85 градусов, положительный вниз |
| Grounded | bool | Существующий CharacterController сервера находится на опоре |
| Crouched | bool | Мотор действительно принял приседание |
| Carrying | bool | Сервер подтвердил удержание предмета или товарища |
| Wounded | bool | Существующее состояние здоровья Wounded |
| Dead | bool | Существующее состояние здоровья Dead |
| Land | trigger, необязательный | Однократно при переходе из воздуха на опору |

Скорость вычисляется после интерполяции сетевой позиции. Входные команды не
используются как доказательство того, что персонаж действительно движется.
Телепорты и недопустимый шаг времени сбрасывают накопленную скорость и приземление.
Драйвер не создаёт игровые шумы, не наносит урон и не перемещает сетевой корень.

При подготовке контроллера нужны реальные переходы/BlendTree и маски, использующие
эти параметры. Для Crossbow Girl следует проверить Humanoid Avatar по настоящим
костям UE5/Quinn. Дополнительные IK-кости не следует автоматически назначать
основными костями Humanoid. Анимации и Avatar в Unity пока не проверены.

52 ARKit blendshape, заявленные в описании, нужно сохранить/восстановить на реальной
геометрии лица и проверить деформации. Пустые morph targets не считаются выполнением.
Функции Unreal Dirt/Snow/Rain и ID-карты требуют отдельной реализации материалов
URP; готовой совместимости с графом Unreal не заявляется.

Art-prefab должен содержать графику и скелет с одним Animator. Игровые скрипты,
NetworkObject, камеры, источники звука, NavMeshAgent и физические тела в нём
проверка отклоняет. AnimationEvents в графической копии клипов также отклоняются,
чтобы визуальная анимация не вызывала игровые действия повторно.
