# Девушка в капюшоне — модель и подключение

Созданы настоящие Blender/FBX файлы персонажа без оружия. Это самостоятельная
реконструкция по трём изображениям Crossbow Girl, которые прислал владелец.
Оригинальная коммерческая модель, текстуры и код Fab не использовались.
Анатомическая основа — графические данные MakeHuman под CC0; точная ревизия:
`Tools/HoodedGirl/MakeHuman/SOURCE.json`.

**Художественная приёмка ещё не пройдена.** Лицо, волосы и ткань отличаются от
референса; точное сходство и фотореализм уровня AAA не подтверждены. Текстуры
процедурные, не фотоскан. Это технический результат для просмотра и оценки.

## Файлы

- `ArtSource/HoodedGirl/HoodedGirl.blend` — редактируемый исходник, T-pose rest,
  исходные части одежды в скрытой коллекции `EDITABLE_SOURCE_PARTS`.
- `Assets/Characters/HoodedGirl/Models/HoodedGirl_LOD0.fbx` и LOD1/LOD2 —
  реальные игровые сетки: 207756 / 125628 / 87401 треугольников.
- `Assets/Characters/HoodedGirl/Textures` — 11 PNG: кожа 4096², остальные 2048².
- `Assets/Characters/HoodedGirl/Documentation` — материалы, кости, анимации,
  семь выражений лица, анализ референсов и характеристики экспорта.
- `ArtSource/HoodedGirl/Previews` — рендеры именно этого исходника в Blender.
- `Tools/HoodedGirl` — скрипты моделирования и проверки.

Риг содержит 55 деформирующих костей, пальцы, глаза и челюсть. В меше `Face`
есть 52 именованные непустые разные ARKit формы. Сохранены 21 телесный клип
и семь лицевых демонстраций. Бюджет геометрии ещё требует профилирования
на четырёх игроках, особенно на Mac.

## Открыть в Blender

Скачать всю ветку через GitHub → Code → Download ZIP и распаковать. Открыть
`ArtSource/HoodedGirl/HoodedGirl.blend` в Blender 5.2. Текстуры внешние:
сохранять расположение папок из ZIP. Анимации доступны в Action Editor;
`FaceDemo_Face`, кадры 1–211, показывает семь выражений. LOD1/2 скрыты.
Для полной пересборки: `bash Tools/HoodedGirl/run_macos.sh`.
Скрипт работает локально без скачивания кода по URL; сохраняет резервные копии.

## Установить в Unity

При `CS1513: } expected` после ручной правки используйте [автоматическую замену полного файла 0.3.2](IMPORT_RECOVERY_032_RU.md).

Если пункт 22 останавливается на `Expected the prepared Humanoid hierarchy`, установите [однофайловое исправление 0.3.1](IMPORT_FIX_031_RU.md).

1. Выйти из Play. Из нового ZIP вручную обновить один файл
   `Assets/_Silence/Editor/SilenceSourceUpdater.cs` в своём проекте.
2. После компиляции: **SILENCE → 00 Update Sources From Folder**. Выбрать
   распакованный корень репозитория с `Assets` и `LocalPackages`.
3. После импорта: **22 Prepare Hooded Girl Assets**. Инструмент создаёт
   материалы URP, Humanoid Avatar, клипы, контроллер, LOD prefab,
   профиль и отдельную демонстрационную сцену из фактических файлов FBX.
4. **23 Open Hooded Girl Preview**, затем Play — оценить модель,
   выражения и клипы. **Это просмотр, он не заменяет игровую сцену.**
5. Открыть свою последнюю доработанную игровую сцену с правильным окружением.
   Не выбирать старую Campaign ради установки. **21 Player Avatar Workshop**
   создаёт отдельную копию именно открытой сцены и её сетевого player prefab.
6. Проверить свой вид и чужого игрока, присед, прыжок, переноску,
   смерть и наблюдателя. Из окна 21 собрать Host и Client.
   У обоих должен быть новый prefab и одинаковый протокол (не меньше 5).

Исходная сцена, её prefab и регистрации других сетевых объектов сохраняются.
Меню 22 не открывает и не пересоздаёт Campaign. URP Lit не воспроизводит
Blender SSS; лицо в Unity нужно оценить отдельно. Голова/капюшон/лицо скрываются
для собственной камеры, тело и руки остаются видимыми. Графические компоненты
не меняют физику и authority движения.

## Проверки и ограничения

`Docs/Validation/HoodedGirl/blender.json` содержит фактические проверки исходника
и повторного импорта трёх FBX: сетки, UV, текстуры, веса, риг, лицевые
формы, клипы и контакт подошв в сохранённых исходных походках на плоском полу.
Контакт не подтверждает анимацию на неровной земле и смешивания Animator.

Unity Editor в облаке отсутствует. Нативная компиляция, импорт Humanoid,
NGO ILPP, Play, руки/коллизии/рендеринг и кооператив **не проверены**.
`NATIVE_CHECKS_RU.md` перечисляет проверки на компьютере владельца.
Синтаксис C# и тесты чистого ядра этого не заменяют.

Оригинальные требования: `MODELING_TASK_RU.txt`; задача подключения:
`TASK_RU.txt`. Фонарик — следующий отдельный этап, требования сохранены
в `Docs/Flashlight/TASK_RU.md`.
