# Visual Rebuild 2.0 — первый участок фермы

Это обновление рабочей игры в отдельной ветке **codex/visual-rebuild**. В комплекте настоящие
FBX-модели, технические PBR-карты и инструменты Unity. Итоговый фотореализм и готовность сцены
ещё не подтверждены. Существующая кампания не перезаписывается; остальные главы не перестраиваются.

## Самый простой способ установить

Blender на Mac устанавливать не нужно: модели уже экспортированы в FBX.

1. На странице ветки GitHub нажми **Code → Download ZIP**, распакуй.
2. Останови Play. **Сначала обязательно замени только**
   `Assets/_Silence/Editor/SilenceSourceUpdater.cs` в своём проекте файлом из нового ZIP.
   Дождись компиляции. Старый updater не копирует FBX/PNG/шейдеры и новый каталог Graphics.
3. **SILENCE → 00 Update Sources From Folder**, выбери распакованную папку с Assets и LocalPackages.
   Дождись импорта новых моделей/текстур и компиляции.
4. **03 Install Multiplayer Package**, дождись компиляции. NGO 2.13.3, Transport 6.6.0 и URP 17.6.0
   оставь установленными. Не устанавливай HDRP и не заменяй manifest проекта.
5. **13 Visual Workshop → Create visual copy (14)**, затем **Validate scene and shaders (15)**.
6. В окне Workshop нажми **Open visual scene**, затем Play → Host → начать раунд.
   Сцена: `Assets/_Silence/Generated/VisualRebuild/Farm_Visual.unity`.
7. Esc → справа **Графика**: Medium/High/Ultra. Зерно/виньетка выключены по умолчанию.

Созданная визуальная копия сохраняется при повторном запуске 14. Ручные правки не удаляются.
Если генерация была прервана, переименуй папку Generated/VisualRebuild через Project и повтори.
Не удаляй Gameplay и не заменяй целиком `_Silence` через Finder.

## Что изменяется

- Первый двор: реальный Terrain 128×128 м с рельефом вокруг существующей игровой зоны, плавными
  четырьмя слоями, колеями и плоскими площадками у существующих зданий/точек появления.
  Площадь игровых маршрутов не расширяется: прежние ограждения и логика границ сохранены.
- Дом и сарай: FBX-меши с архитектурными деталями, отдельные двери/мебель/забор/радио, три LOD.
  Новые здания накладываются на существующие коллайдеры и интерактивные корни. Старые визуальные
  renderers скрываются только в копии; NetworkObject, RPC, масса, шум и правила взаимодействия сохранены.
- Детали окружения: авторские сосны трёх форм с LOD, камни/папоротники, травяной Terrain-слой.
  Размещение по фиксированному seed, с отступами от дорог и помещений, а не чистый случайный scatter.
- Профиль ACES, умеренная цветокоррекция и bloom, SMAA; реальный мягкий cookie/тени фонарика.
  Инерция только у света, камера и луч взаимодействия не смещаются. Motion blur и aberration отключены.
- Локальный ограниченный высотный single-scattering fog с учётом depth/теней основного света,
  приближённым рассеянием конуса фонаря; умеренная плотность не скрывает окружение.
- Physical procedural sky, мотивированные светильники, realtime reflection probes, точки light probes,
  три графических профиля. Runtime клонирует URP asset, не перезаписывает общий pipeline проекта.

Это технический и художественный первый проход. Авторские карты процедурные, не фотографические
сканы. Процедурный лес — кандидат для оценки, не утверждённый финальный лес. Персонажи/существо
пока используют прежний временный арт. [Точный список недостающих ассетов](ASSET_REQUIREMENTS_RU.md).

## Реальные доступные проверки

- Проверены PNG/каналы/normal vectors, Terrain samples/веса/ровные площадки и бинарные FBX.
- Blender проверил геометрию реальных проёмов, уменьшение LOD, повторный импорт экспортированных
  FBX, единицы измерения и UV. Отдельные отчёты в Docs/Validation/VisualRebuild.
- Сделаны [рендеры ассетов в Blender](Previews/README.md). Это **не скриншоты Unity**.
- C# проверяется Roslyn в пяти наборах define и структурным checker. Это не API binding/ILPP.
- В облаке нет Unity Editor/лицензии: 14/15, компиляция шейдеров в URP 17.6/Metal, реальное
  визуальное качество, физика, навигация, кооператив и FPS здесь **не проверены**.

## Приёмка у владельца

1. 15 даёт Failures: 0, материалы не розовые, Console без красных ошибок; Linear color space.
   Если проект Gamma, Workshop предлагает отдельную кнопку переключения (вызовет переимпорт).
2. В Workshop **Run native gameplay regression**: используется настоящая визуальная сцена,
   результат `Library/Silence/VisualGameplayChecks.json`. Существующий probe отключает checkpoint-запись
   и частично вызывает доменные действия напрямую; он не заменяет ручное прохождение/сеть.
3. Проверить пешком: дверь/ворота/окна, проходы, стол/радио/подбор, приседание/лестницу, шаги на
   земле/дорожке/стекле, броски, существо, выход и следующую главу. Старый ground collider заменён
   Terrain; NavMesh фермы пересобирается. Другие шесть NavMesh не заменяются.
4. Осмотреть с фонариком в доме, снаружи и на границе света. В Play у VisualAtmosphere можно задать
   время 12 / 17.3 / 23 для проверки дня/сумерек/ночи. Проверить отсутствие засветки сквозь стены.
5. Кнопка **Capture actual Game view + camera record** сохраняет настоящий Game PNG и положение
   камеры в Library/Silence/VisualCaptures. Дождаться конца кадра и проверить наличие PNG.
6. **Build visual Host + Client** из Workshop, затем меню 07 запуска обеих сборок. Меню 10 по-прежнему
   собирает прежнюю кампанию; его не использовать для визуальной копии. Проверить 2/4 процесса:
   одинаковый декор, одиночный подбор, двери, переноска, шум/ИИ и переходы. Обе стороны пересобрать.
7. В Lighting window проверить baked-GI settings. Workshop может запустить BakeAsync в открытой
   визуальной сцене. Lightmaps/запечённые probes здесь не создавались и не выдаются за готовые.
8. **Record 15 seconds of actual performance** в Workshop пишет настоящие frame samples, p95,
   память и доступный GPU timing в Library/Silence/VisualPerformance-*.json. Это замер Editor,
   не сертификат standalone-билда; GPU timing может отсутствовать. Профилировать Medium/High/Ultra на M1 Pro: frame time CPU/GPU, foliage overdraw, тени,
   reflection probes, fog cost, GPU memory, GC allocations. Ни 60 FPS, ни бюджет памяти пока не подтверждены.

## Известные ограничения

Нет полноценной художественной приёмки, внешних качественных rigged-персонажей, production-анимации,
сканов материалов, декалей трещин/влаги, готовых baked lightmaps, SSAO/contact-shadow renderer feature,
фотореалистичного облачного неба и полного volumetric lighting всех источников. Fog — ограниченное
приближение: depth завершает луч у видимой поверхности, но затенение конуса фонаря внутри тумана
не является полной shadow-map интеграцией. Основные тени фонаря на геометрии задаёт штатный URP.
Shader/API review по доступному upstream не заменяет компиляцию точного установленного URP.

Следующий этап — получить и оценить настоящие Unity-кадры с этого небольшого участка,
исправить свет/материалы/стыки и только после подтверждения качества расширять художественную работу.
