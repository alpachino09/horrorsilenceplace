# Арт: что готово к проверке и что ещё нужно

Внешние игровые модели не скачаны. Авторские FBX и PBR-карты созданы для SILENCE из исходников
Tools/VisualRebuild. Их нельзя объявлять фотограмметрией, фотореализмом или принятым production-артом.

| Группа | Текущая поставка | Статус |
|---|---|---|
| Дом | Реальные оконные/дверной проёмы, толщина стен, фундамент, обшивка, три LOD, крыша с отдельными элементами, водостоки, труба, балки, лестница/чердак, светильник/проводка | Авторская базовая архитектура; требует художественной и Unity-проверки |
| Сарай | Проём под существующую дверь, деревянные конструкции/стропила, кровля, три LOD | Требует износа/обстановки и проверки в Unity |
| Предметы | Дверь с петлями/ручкой, стол, шкаф/книги, забор, ящик, банка, радио, потолочный светильник | Авторские модели; износ и масштабы проверить близко |
| Природа | 3 процедурных сосны × 3 LOD, 3 камня, папоротник, травяной атлас, четыре слоя Terrain | Пробный арт для проверки системы; финальный реалистичный лес ещё не принят |
| Текстуры | 11 наборов 1K: base color, normal, packed metallic/AO/height/smoothness; 3 alpha-атласа и cookie | Технически проверены; близкие планы и тайлинг требуют художественной доработки |
| Персонажи и существо | Существующая временная графика сохранена | Нужны качественные rigged-модели; V5 не завершён |

## Следующие необходимые ресурсы

- **Лес умеренного пояса:** сосны 3 возраста × 3–4 варианта, берёзы/лиственные 3–4 варианта.
  Реальный масштаб 5–18 м, 15–40k треугольников LOD0, 4–12k LOD1, 0.8–3k LOD2, дальний impostor;
  2K bark + 2K/4K opacity foliage atlas, normal/roughness/AO, корректные normals карточек, wind weights,
  pivot у основания. FBX, отдельные LOD meshes, простые trunk colliders; проверить лицензию именно модели.
- **Подлесок:** 5–8 кустов/папоротников, пни/корни/валежник по 3 варианта. 0.5–6k треугольников,
  1K/2K PBR, alpha cutout; детали без игровых коллизий, крупный валежник с отдельным простым коллайдером.
- **Сканированные поверхности:** старая крашеная доска, штукатурка с пятнами, кирпич с повреждениями,
  лесная подстилка и влажная грязь. Бесшовные 2K/4K basecolor/normal GL/roughness/AO/height,
  метрический размер образца, без запечённого направленного света. Источники для проверки:
  https://polyhaven.com/textures и https://ambientcg.com/ (обычно CC0, проверять карточку каждого ассета).
- **Человек:** 1.7–1.9 м, FBX Humanoid, LOD0 ≤40k треугольников, LOD1 ≤15k, LOD2 ≤5k, 2K PBR,
  idle/walk/run/crouch/carry/wound/death/revive, in-place без root motion. Риг и Animator должны
  следовать серверному движению; CharacterController и сетевые компоненты на прежнем корне сохраняются.
- **Слепое существо:** силуэт по GDD, без визуального обнаружения игрока, LOD0 ≤50k, 2K/4K PBR,
  idle/patrol/investigate/search/chase/attack/recover/break animations. Скорость анимации согласовать
  с NavMeshAgent; не включать root motion или новую логику восприятия из импортированного пакета.
- **Окружение комнаты:** согласованный набор американской сельской мебели/утвари, 1–5k треугольников
  на небольшую вещь, 1K/2K PBR, исходный автор и лицензия. Назначение предметов осмысленное, без
  случайного засорения помещения или новых шумовых источников без отдельного анализа.

Модели нужно вставлять визуальными дочерними объектами существующих Player/Creature/Interactable;
не переносить/заменять их корни и NetworkObject. LOD-представления не получают отдельные NetworkObject.
Внешние модели очищать от чужих controller/AI/network scripts, камер и звуков. Капсулы временного
арта не считать финальным персонажем. Платные покупки автоматически не выполнялись.
