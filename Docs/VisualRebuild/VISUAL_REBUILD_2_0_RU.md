# SILENCE — VISUAL REBUILD 2.0
## Полная реконструкция графики, окружения и визуального качества Unity-хоррора

**Репозиторий:** `alpachino09/horrorsilenceplace`

**Твоя роль:** Lead Unity Graphics Programmer, Senior Technical Artist, Environment Artist, Level Designer, Lighting Artist и Technical Director.

**Главная задача:** кардинально изменить визуальное качество существующей игры SILENCE. Текущая графика слишком простая, условная, местами мультяшная и недостаточно атмосферная.

Необходимо добиться визуального качества, максимально приближенного к современным реалистичным ПК-хоррорам.

Это не просьба написать рекомендации. Это задача по непосредственной реализации в Unity.

8. Создавай реальные сцены, материалы, префабы, настройки и компоненты.

11. Проверяй результат, а не только успешность написания C#.
12. Если какой-либо этап невозможно завершить без Unity Editor, внешних моделей или действий владельца проекта, точно укажи ограничение и продолжай выполнять остальные доступные этапы.

**Начни реализацию сразу после короткого технического аудита. Не жди дополнительного подтверждения для безопасных, обратимых изменений.**

# 3. ТЕХНИЧЕСКИЙ АУДИТ UNITY

До изменения проекта определи:

- точную версию Unity;
- используемый Render Pipeline;
- целевую платформу;
- настройки качества;
- список основных сцен;
- существующую систему освещения;
- используемые шейдеры;
- наличие Terrain;
- наличие моделей, текстур и префабов;
- текущую структуру сцены;
- существующую сетевую архитектуру;
- состояние систем передвижения и шума.

Особенно важно проверить совместимость с Unity 6.6, если именно эта версия используется в проекте.

## Выбор Render Pipeline

Цель — HDRP для ПК, если проект совместим с ним.

Если используется URP:
1. Оцени сложность миграции.
2. Проверь совместимость всех используемых шейдеров.
3. Проверь зависимости и пакеты.
4. Определи риски поломки существующих сцен.
5. Не выполняй необратимую миграцию без резервной ветки.

Если переход на HDRP создаёт чрезмерные риски, реализуй максимально качественный визуальный результат на URP и объясни причины выбора.

Не считай HDRP автоматической гарантией качественной графики.

# 4. ПОЛНАЯ РЕКОНСТРУКЦИЯ ЛАНДШАФТА

Текущие примитивные поверхности должны быть заменены полноценным реалистичным окружением.

## Рельеф

Используй Unity Terrain или совместимую систему.

Создай:
- естественные перепады высоты;
- неровности;
- небольшие холмы;
- углубления;
- дорожные колеи;
- канавы;
- естественные склоны;
- участки каменистого грунта;
- переходы между типами поверхности.

Избегай случайного шума без геологической логики.

## Материалы земли

Необходимы PBR-материалы:

- сухая почва;
- влажная почва;
- грязь;
- трава;
- гравий;
- камни;
- лесная подстилка;
- древесные остатки;
- мох.

Используй:
- albedo/base color;
- normal maps;
- mask maps;
- smoothness;
- ambient occlusion;
- height blending, если поддерживается.

Применяй текстуры достаточного разрешения с учётом расстояния до камеры, анизотропной фильтрации, mipmaps и бюджета видеопамяти.

## Смешивание материалов

Убери резкие искусственные границы.

Переходы должны учитывать:
- уклон;
- высоту;
- влажность;
- тип грунта;
- расположение дорог;
- окружение построек.

# 5. ЛЕС И РАСТИТЕЛЬНОСТЬ

Лес должен выглядеть естественным и плотным, а не как набор одинаковых деревьев.

## Деревья

Используй качественные модели с:
- реалистичной геометрией стволов;
- корой;
- ветками;
- листвой;
- разными размерами;
- вариациями формы;
- естественным расположением.

Для каждой породы используй несколько визуальных вариантов.

## Подлесок

Добавь:
- кустарники;
- сухие ветки;
- упавшие стволы;
- пни;
- корни;
- папоротники;
- небольшие растения;
- камни;
- листья;
- лесной мусор.

Размещай растительность по правилам биома, а не чисто случайным образом.

## Поведение

Реализуй умеренную реакцию листвы на ветер.

Ветер не должен выглядеть как синхронное движение всех деревьев.

## Оптимизация

Используй:
- LOD;
- GPU instancing, где применимо;
- culling;
- оптимизированные шейдеры листвы;
- корректную настройку теней.

Если качественных моделей нет, подготовь систему размещения и список необходимых ассетов. Не заменяй финальный лес деревьями из цилиндров и шаров.

# 8. ОСВЕЩЕНИЕ

Освещение должно быть кинематографичным, но физически убедительным.

## Наружное освещение

Настрой:
- естественное направление света;
- атмосферное рассеивание;
- корректный цвет окружающего света;
- мягкость теней;
- баланс прямого и непрямого освещения.

## Внутреннее освещение

Используй мотивированные источники:
- лампы;
- фонари;
- свет из окон;
- аварийные светильники;
- внешнее освещение через проёмы.

Не добавляй невидимые источники света без необходимости.

## Тени

Настрой:
- качественные динамические тени;
- контактные тени;
- корректное затенение небольших объектов;
- разумную дальность теней;
- устранение shadow acne и light leaking.

## Глобальное освещение

Выбери подходящий метод GI в зависимости от платформы, версии Unity и динамичности сцены.

Не используй дорогие технологии исключительно ради названия.

## Тестирование

Проверь освещение:
- днём;
- ночью;
- внутри помещений;
- при использовании фонарика;
- на границе света и тени.

## Атмосферные эффекты

По необходимости реализуй:
- пыль в лучах света;
- лёгкую дымку;
- влажный воздух;
- частицы дождя;
- капли на поверхностях;
- локальные частицы грязи.

Не используй слишком много частиц без профилирования.

# 10. ФОНАРИК

Фонарик — важнейший визуальный инструмент хоррора.

Реализуй:
- реалистичное световое пятно;
- физически убедительное затухание;
- корректные тени;
- освещение мелких деталей;
- взаимодействие с туманом;
- мягкие края светового конуса;
- естественную привязку к рукам или камере.

Не используй чрезмерную случайную тряску.

Свет фонарика должен позволять рассматривать качественно проработанное окружение.

# 11. КАМЕРА ОТ ПЕРВОГО ЛИЦА

Цель — естественное восприятие человека, а не аркадная камера.

## Настрой

- правильная высота камеры;
- реалистичный FOV;
- естественное ускорение;
- аккуратная инерция;
- плавные повороты;
- минимальный head bob;
- корректная работа в узких помещениях;
- отсутствие прохождения камеры сквозь геометрию.

## Постобработка

Используй:
- умеренную цветокоррекцию;
- корректную экспозицию;
- тональную компрессию;
- умеренный bloom;
- качественное сглаживание.

Motion blur, film grain, vignette и chromatic aberration должны быть отключаемыми и по умолчанию применяться сдержанно.

Не создавай фальшивый реализм за счёт сильного размытия изображения.

# 12. СИСТЕМА ЗВУКА И ВИЗУАЛЬНАЯ АТМОСФЕРА

SILENCE — хоррор, в котором звук представляет опасность.

Поэтому графика должна поддерживать эту механику.

## Визуальное поведение окружения

Продумай:
- реакцию растительности на движение;
- взаимодействие дверей;
- движение небольших физических предметов;
- освещение мест, где игрок может создать шум;
- визуальные признаки опасных поверхностей.

## Взаимодействия

Объекты должны реагировать естественно:
- двери открываются вокруг корректной оси;
- предметы имеют адекватную массу;
- коллизии соответствуют форме;
- физические объекты не дрожат без причины;
- материалы соответствуют звукам взаимодействия.

Не меняй баланс системы шума без анализа существующей механики.

# 13. ПЕРСОНАЖИ И ПРОТИВНИКИ

Проверь визуальное качество существующих персонажей.

Для персонажей необходимы:
- качественные модели;
- корректные пропорции;
- анимации ходьбы;
- анимации приседания;

- корректные тени;

Для существ:
- устрашающий, но биологически убедительный силуэт;

- качественные анимации;
- отсутствие скольжения при движении;
- корректное взаимодействие с окружением.

Не создавай новые модели монстров, противоречащие существующему GDD.

Если подходящих моделей нет, подготовь технические требования к ассетам и интеграционные префабы.

# 15. ПРОЦЕДУРНЫЕ ИНСТРУМЕНТЫ

Создай Editor Tools для ускорения построения уровней.

Желательные инструменты:

### TerrainBuilder
Генерация и редактирование рельефа.

### VegetationPainter
Размещение растительности по маскам плотности, уклона и биома.

### BuildingAssembler
Сборка зданий из модульных элементов.

### EnvironmentScatter
Размещение камней, веток, мусора и других деталей с учётом коллизий и правил окружения.

### LightingConfigurator
Настройка профилей освещения.

### SceneValidator
Проверка:
- отсутствующих материалов;
- сломанных ссылок;
- некорректных коллайдеров;
- отсутствующих LOD;
- проблемных источников света;
- неподдерживаемых шейдеров.

### GraphicsQualityManager
Управление пресетами качества.

Для каждого инструмента создай понятный интерфейс в Unity Editor.

Генерация должна быть воспроизводимой через seed и не должна разрушать вручную отредактированные объекты.
