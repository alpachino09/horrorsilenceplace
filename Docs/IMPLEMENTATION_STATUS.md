# Фактическое состояние SILENCE — 0.3.0

Написан игровой цикл за пределами первоначальной фермы. Исходный GDD, архитектура,
технический план и 126 ответов сохранены. Последнее прямое указание владельца разрешило
продолжать разработку без ожидания его возвращения. Готовая production-игра не заявляется.

## Созданный код

- Чистые модели: здоровье, выносливость, слуховая память, поверхности, микрофонная огибающая,
  кампания, развязки, голосование, лимит запросов, 3/5-местный инвентарь.
- Runtime: слуховой NavMesh-ИИ, контактные атаки, отмеченные разрушаемые двери, препятствия/маскирование,
  серверная переноска/броски, ручные двери, лечение/спасение/перенос союзника, наблюдение, wipe.
- Кампания: семь ChapterDefinition, процедурные локации, общие цели, переходы, флаги и checkpoint JSON.
- UI RU/EN, инвентарь, журнал главы, настройки, голосование; минимальный HUD без постоянного прицела.
- Опциональный микрофон после разрешения ОС: только числовая громкость для ИИ. Голосовой связи нет.
- Сетевые команды/снимки предметов, физики, здоровья, существа и кампании; серверная власть сохранена.
- Генератор 09, сборки 10, валидатор 11, нативная проверка 12. Они создают новые ассеты отдельно от старой фермы.

Исходники реально созданы. Сами Campaign.unity, префабы и NavMeshData появятся после выполнения
генератора в Unity; их YAML не выдумывался вручную. Контент и графика остаются временными.

## Оценка текущего этапа

**75% подготовительного блока**, не процент готовности всей игры. Четыре равных части:

1. Модели и исполняемые тесты — выполнено.
2. Runtime и сетевые адаптеры — написаны.
3. Генераторы, инструменты и доступные облачные проверки — подготовлены.
4. Нативная Unity-компиляция, реальное прохождение и кооператив — ожидают выполнения.

Процент не означает, что три четверти всей игры уже завершены. Плановые 4–6 часов,
финальный арт, озвучка, NPC/постановки, лазание, второй вариант существа, жесты/внешность,
proximity/radio voice, Steam/Relay, поздний вход на checkpoint, полные настройки управления,
стриминг локаций и производительность ещё требуют разработки и приёмки.

[Короткая инструкция и подробные сценарии](GAMEPLAY_RU.md): обновить через 00, подключить 03,
создать 09, проверить 11, выполнить 12, затем вручную пройти и проверить сборки 10 в 2/4 процессах.
Следующий этап: исправления по настоящим Unity-результатам и доведение первой главы
до законченного эпизода с полноценным арт/аудио и авторскими сюжетными сценами.
