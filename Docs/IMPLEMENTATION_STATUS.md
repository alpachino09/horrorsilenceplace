В облаке нет Unity Editor/Hub/лицензии. На скриншотах владельца подтверждена Unity 6.6 (6000.6.7f1), Mac/Metal.

Они не подделывались. Unity Registry ответил HTTP 403; исходники официального NGO получены с GitHub.

## Ранее проверено владельцем

В Unity появились команды меню 01/02, созданы Bootstrap/Farm_Prototype и ассеты. Скриншот Play Mode
подтвердил изображение фермы/меню; владелец затем подтвердил движение, обзор, бег, приседание,
прыжок, дверь, фонарь и меню. Это ручное сообщение владельца о предыдущей версии, не облачный тест.
Полный инвентарь, маршрут до выхода, повторная генерация, потолок и Unity Test Runner ещё не подтверждены.
Новые изменения требуют повторной проверки этого одиночного режима.

## Ограничения

Серверный ввод без client prediction: задержка движения заметна на высоком ping. Интернет/Relay/Steam,
host migration, восстановление игрока посреди раунда, микрофон/голос не реализованы.
Повторный вход допускается в новом лобби; во время раунда он явно отклоняется.
Двери кнопочные, радио — индикатор без аудио. Физическая переноска/бросок — Sprint04.
Нет ИИ/шагов/ранений/кампании/сохранений/редактора внешности. Временная геометрия сохраняется.
Рендеринг и управление меню не стали художественно завершёнными. Платные ресурсы не использованы.
