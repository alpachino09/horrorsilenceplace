# SILENCE — фактическое состояние Sprint 00–01

Дата: 2026-10-22. Выполнена реализация исходников; Unity-приёмка остаётся открытой.

## Среда и граница готовности

Исходный `alpachino09/horrorsilenceplace` был пуст: без коммитов, Unity-проекта, манифестов,
сцен и пользовательских изменений. Unity Editor/Hub в доступной облачной среде не обнаружены.
Поэтому точная версия Unity, установленные Unity-пакеты и лицензия Editor не подтверждены.
Пакет рассчитан на Unity 6 / URP и официальный Input System, но не выдаётся за проект,
созданный и открытый в Editor. `ProjectVersion.txt` и версии Unity-пакетов не подделывались.

## Что реализовано в коде

- Структура Assets/_Silence, пять сборок, документация, Unity .gitignore, исходный пакет требований.
- SilenceSceneGenerator: создание Bootstrap/Farm_Prototype, Player.prefab, PlayerSettings,
  трёх ItemDefinition и материалов из primitives/URP Lit. Генератор сохраняет текущую сцену,
  не перезаписывает ранее созданные ассеты и сохраняет существующие записи Build Settings.
- Ферма: ограда/ворота, дом, сарай, лестница/площадка, дорожка, низкий навес, освещение и туман.
- Игрок: CharacterController, обзор, ходьба, бег, прыжок, приседание с проверкой потолка,
  фонарь; WASD/мышь и геймпад через отдельный Input Actions asset.
- Взаимодействие: raycast-подсказка в пределах дальности без постоянного прицела;
  повторная проверка в слое полномочий; кнопочные двери/ворота, индикатор радио,
  подбор предметов в 3 слота, табличка завершения маршрута.
- RU/EN для реализованных сообщений, показ инвентаря, меню чувствительности/VSync/дальности теней.
- Основа расширения сети: IWorldAuthority, локальная привязка владельца, отдельная offline-реализация,
  числовые контракты NoiseEvent/NoiseSystem. **Сетевого соединения и репликации пока нет.**

Ни один пункт Unity-поведения выше ещё не подтверждён запуском Editor. Это перечень реализованного кода.
Сами `.unity`, `.prefab`, `.mat`, `.asset` пока не созданы на диске: их создаст генератор в настоящем Unity.

## Известные ограничения

Двери пока переключаются кнопкой, предметы попадают в инвентарь без физической переноски/броска,
радио не воспроизводит аудио. Нет шагов по материалам, ИИ, ранений, стамины, кампании и её сохранений,
микрофона, голосового провайдера, сетевого транспорта, меню перепривязки и полноценной навигации
по меню с геймпада. Семь глав остаются требованиями; готовой кампании нет.
Затухание шума — ограниченная игровая формула, а не физическая акустика; raycast-occlusion ещё не реализован.
Базовая маскировка ограничена 85%: фон сам по себе не обнуляет слышимость.
