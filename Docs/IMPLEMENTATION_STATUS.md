# SILENCE — фактическое состояние Sprint 00–01

Обновлено: 2026-10-23. Первичный запуск фермы и базовое управление подтверждены владельцем;
оставшиеся пункты Unity-приёмки остаются открытыми.

## Среда и граница готовности

Исходный `alpachino09/horrorsilenceplace` был пуст: без коммитов, Unity-проекта, манифестов,
сцен и пользовательских изменений. Unity Editor/Hub в доступной облачной среде не обнаружены.
На последующем скриншоте владельца подтверждена Unity 6.6 (6000.6.7f1) на Mac.
Версии установленных Unity-пакетов и лицензия облачного Editor не подтверждены.
Пакет рассчитан на Unity 6 / URP и официальный Input System, но не выдаётся за проект,
созданный и открытый в Editor. `ProjectVersion.txt` и версии Unity-пакетов не подделывались.

## Что реализовано в коде

- Структура Assets/_Silence, пять сборок, документация, Unity .gitignore, исходный пакет требований.
- SilenceSceneGenerator: создание Bootstrap/Farm_Prototype, Player.prefab, PlayerSettings,
  трёх ItemDefinition и материалов из primitives/URP Lit. Генератор сохраняет текущую сцену,
  не перезаписывает ранее созданные ассеты и сохраняет существующие записи Build Settings.
- Ферма: ограда/ворота, дом, сарай, лестница/площадка, дорожка, низкий навес, освещение и туман.
- Игрок: CharacterController, обзор, ходьба, бег, прыжок, приседание с проверкой потолка,
  фонарь; WASD/мышь и геймпад через отдельный Input Actions asset.
- Взаимодействие: raycast-подсказка в пределах дальности без постоянного прицела;
  повторная проверка в слое полномочий; кнопочные двери/ворота, индикатор радио,
  подбор предметов в 3 слота, табличка завершения маршрута.
- RU/EN для реализованных сообщений, показ инвентаря, меню чувствительности/VSync/дальности теней.
- Основа расширения сети: IWorldAuthority, локальная привязка владельца, отдельная offline-реализация,
  числовые контракты NoiseEvent/NoiseSystem. **Сетевого соединения и репликации пока нет.**

На Mac владельца появились команды меню, генератор сообщил об успешном создании сцен,
а скриншот Play Mode показал Farm_Prototype, изображение с камеры и стартовое меню.
Владелец затем подтвердил перечисленную ему ручную проверку: ходьба/обзор, бег, приседание,
прыжок, открывание двери, фонарь и возврат в меню. Это ручная проверка владельца,
а не автоматический запуск Unity в облаке.
Сгенерированные `.unity`, `.prefab`, `.mat`, `.asset` находятся в локальном проекте владельца;
в этом checkout их пока нет. Работа инвентаря, полный маршрут, повторная генерация и тесты Unity
по этой проверке ещё не подтверждены.

## Известные ограничения

Двери пока переключаются кнопкой, предметы попадают в инвентарь без физической переноски/броска,
радио не воспроизводит аудио. Нет шагов по материалам, ИИ, ранений, стамины, кампании и её сохранений,
микрофона, голосового провайдера, сетевого транспорта, меню перепривязки и полноценной навигации
по меню с геймпада. Семь глав остаются требованиями; готовой кампании нет.
Затухание шума — ограниченная игровая формула, а не физическая акустика; raycast-occlusion ещё не реализован.
Базовая маскировка ограничена 85%: фон сам по себе не обнуляет слышимость.

## Следующее действие

При импорте на машине владельца обнаружен CS0619: установленный Unity запрещает
`Object.GetInstanceID()`. В OfflineWorldAuthority вызов удалён: единственный зарегистрированный
offline-игрок получает локальный SourceId 1. Это не сетевой ID; для NGO потребуется серверное
сопоставление сущностей. Владелец применил ручную замену; последующий запуск фермы подтверждён.

Следующий скриншот владельца выявил две ошибки редакторской сборки: неоднозначный `PackageInfo`
и запрещённый `SerializedProperty.objectReferenceInstanceIDValue`. В валидаторе указано полное имя
`UnityEditor.PackageManager.PackageInfo`; для Unity 6.6+ используется `objectReferenceEntityIdValue`
с проверкой пустого EntityId. Для более ранних Unity 6 сохранена отдельная ветка компиляции.
Устаревание свойства сверено с официальным UnityCsReference; синтаксис обеих веток проверяется Roslyn.
Владелец применил эквивалентные ручные замены; затем подтвердил появление обеих команд меню
и предоставил скриншот запущенной фермы.

Владельцу: проверить подбор 3 из 4 предметов, отсутствие исчезновения четвёртого при полном
инвентаре и завершение маршрута через ворота. Затем выполнить оставшуюся ручную приёмку,
EditMode/PlayMode-тесты и передать `Library/Silence/Validation.txt` с итогом и версиями пакетов.
Инструкции даны в README_RU.md и MANUAL_TESTS_RU.md.

Следующий программный этап: сначала исправить найденные при Unity-приёмке ошибки Sprint 00–01,
затем Sprint 02 — настоящий NGO/Transport Host+Client с серверным состоянием и тестом двух процессов.
Передача исходников через GitHub разрешена владельцем отдельно; ветка для передачи —
`codex/silence-sprint-00-01`. Факт публикации отделяется от ручной проверки владельца:
автоматические Unity-тесты и остальные пункты приёмки по-прежнему необходимо выполнить.
