# Старый код продолжает выполняться — прямая установка 0.4.9

После очистки Console пользователь снова получил прежний текст
«Пустые bounds» и Debug.LogError на строке 58 CharacterReworkWorkshop.cs.
Этого текста нет в опубликованном исходнике 0.4.8, а его логирование находится
на строке 65. Скриншот показывает новый запуск проверки, поэтому это уже
не объясняется только старой записью Console. Точная причина, почему на Mac
не применился новый код (выбранная папка, другой проект, компиляция, reload),
ещё неизвестна. Повторная генерация мира не обновляет исходники и не помогает.

## Установка через Terminal

1. Сохрани открытый игровой мир и **закрой Unity**.
2. Скачай `Downloads/SILENCE_HumanMotion_0.4.9.zip` через **Download raw file**.
   Распакуй в Downloads. Внутри папки обновления находится
   `Install_Bounds_Fix.command` рядом с Assets и LocalPackages.
3. Открой стандартное приложение macOS **Terminal**, вставь одну команду:

   ```bash
   bash ~/Downloads/SILENCE_HumanMotion_0.4.9/Install_Bounds_Fix.command
   ```

4. В открывшемся окне Finder выбери **папку своего Unity-проекта**. В ней
   лежат Assets, Packages, ProjectSettings. Не выбирай папку обновления.
5. Дождись сообщения «Установлена проверка bounds 0.4.9». Terminal покажет
   точный путь проекта. Открой **этот проект** в Unity Hub, дождись компиляции.
6. Открой **SILENCE → 27**. Вверху должны быть **«Версия проверки: 0.4.9»**,
   путь проекта и открытый мир. Выбери только **«Проверить ссылки камеры
   и персонажа»** в уже созданном мире `..._Character`.

Ещё одну копию мира создавать не нужно. Можно остаться в уже открытой
`Campaign_Vesper_Player_Motion_Character_Character_Character_Character`.
При `Failures: 0` — Play, создание сессии, начало раунда, V для камеры.

Если скрипт сообщает «No such file or directory», папка распаковалась в другое
место: введи в Terminal `bash ` с пробелом, перетащи туда
`Install_Bounds_Fix.command` из Finder и нажми Enter.

Если надпись версии не появилась, пришли первую новую ошибку компиляции
`CS…`. Если новая проверка сообщает «Некорректные bounds», пришли весь
отчёт с номером версии и числовыми значениями center/extents.

## Что делает скрипт

- Работает с локальными файлами из распакованного архива, без скачивания
  кода во время установки, sudo или изменения настроек macOS.
- Проверяет SHA-256 исходных файлов до изменений и SHA-256 записанных файлов.
- Заменяет целиком только CharacterReworkWorkshop.cs и SkinBoundsModel.cs.
  Это видимая версия проверки и исправление мелких локальных bounds из 0.4.8.
- Перед первой заменой сохраняет оба прежних файла в
  `Library/Silence/SourceBackups/BoundsFix-0.4.9-…/`.
- При ошибке копирования/проверки восстанавливает оба файла из резервной копии.
- Сохраняет сведения об успешной установке в
  `Library/Silence/BoundsFixInstalled.txt`.
- Не меняет .meta, сцены, модели, материалы, prefab, анимации, Packages
  и проектные настройки. Обход проверки настоящей пустой геометрии не добавлен.

Обычная полная установка кода через 00 тоже доступна, но для текущей
ситуации прямой скрипт сокращает число шагов и проверяет конкретные два файла.

## Проверки

Пять тестов запускают **точный скрипт из ZIP** на временных проектах:
успешная замена/сохранение meta и мира/backup, неправильная папка,
повреждённый исходник, отказ второй записи с откатом, повторная установка.
Пути с пробелами включены. Проверена bash-синтаксическая корректность.
Эти проверки выполнялись в Linux; нативный macOS Finder picker и Unity
Test Runner/компиляция/Play в облаке недоступны и не считаются пройденными.
Математическое исправление bounds не изменялось; его 222 Core-теста прошли
при подготовке 0.4.8. Результаты доставки и установки:
`Docs/Validation/InstallFix049/`.
