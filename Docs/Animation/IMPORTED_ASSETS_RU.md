# ObjectiveEnvironment_Assets + Kevin Iglesias — 0.5.0

Окно **SILENCE → 28 Imported Textures and Human Motions** подключает два
уже импортированных пользователем пакета к копии **текущего** игрового мира:

- [Realistic Terrain Textures Free, 279940](https://assetstore.unity.com/packages/2d/textures-materials/floors/realistic-terrain-textures-free-279940)
  — пользователь подтвердил папку **ObjectiveEnvironment_Assets**;
- [Human Basic Motions FREE, 154271](https://assetstore.unity.com/packages/3d/animations/human-basic-motions-free-154271)
  — пользователь подтвердил папку **Kevin Iglesias**.

Human Basic Motions не подменяется прежним пакетом PolyOne. В отличие от 25,
новое окно не требует 23 фиксированных `.anim` и не проверяет SHA старого
архива. Оно находит фактические Humanoid-клипы, включая подресурсы FBX.
Сами лицензионные пакеты в обновление/репозиторий не включены.

## Установка на Mac

1. Сохрани свой нынешний игровой мир с героиней и **закрой Unity**.
2. Скачай `Downloads/SILENCE_HumanMotion_0.5.0.zip` через **Download raw file**,
   распакуй в Downloads. В Terminal:

   ```bash
   bash ~/Downloads/SILENCE_HumanMotion_0.5.0/Install_Update.command
   ```

3. Выбери **папку Unity-проекта**, где находятся Assets, Packages,
   ProjectSettings и LocalPackages. Скрипт устанавливает весь собственный
   код, проверяет SHA-256 и делает backup в Library/Silence/SourceBackups.
   Новые файлы тоже устанавливаются; при сбое старые восстанавливаются,
   добавленные файлы удаляются. .meta и импортированные пакеты сохраняются.
4. Открой **этот проект**, дождись компиляции. Оставь открытым свой нынешний
   мир, например последний `..._Character`; исходную Campaign не открывай.
5. **SILENCE → 28 Imported Textures and Human Motions**. Вверху — 0.5.0.
   Папки должны определиться как **ObjectiveEnvironment_Assets** и
   **Kevin Iglesias**. При необходимости перетащи соответствующие папки
   из Project в поля окна.
6. Нажми **«Найти импортированные ассеты и предложить назначения»**.
7. Проверь выбранные наборы для травы, почвы, гравия и лесной земли.
   Необязательную категорию можно оставить прежней. Размер повтора —
   по умолчанию 4 м, регулируется до создания копии.
8. Назначь **Покой, Ходьбу, Бег**. В каждом поле есть список фактически
   найденных клипов с путями. Предпочитаются female/in-place/вариант 01,
   если распознаются эти обозначения. При равных кандидатах выбор остаётся
   пустым — выбери нужный вручную. Необязательные движения раскрываются
   в «Дополнительные движения и карты PBR».
   Если отдельный спринт не найден, для Shift предлагается тот же реальный
   клип бега с измеренной скоростью воспроизведения; назначение видно в
   дополнительных движениях, его можно изменить или очистить.
9. Нажми **«Создать копию текущего мира с выбранными ассетами»** один раз.
   Дождись измерения анимаций и установки. Откроется новый `..._Assets` мир.
10. Нажми **«Проверить подключённые текстуры и движения»**, затем Play,
    создание сессии, начало раунда. V — осмотреть героиню со стороны.

Вместо Terminal доступен обычный **00 Update Sources From Folder** из этого
архива. Скрипт `Install_Update.command` удобнее после прежней ситуации,
когда Unity продолжала выполнять старые файлы. Отдельный старый
`Install_Bounds_Fix.command` устанавливает только проверку bounds и не
устанавливает окно 28.

## Что меняется в копии

**Земля.** Копируются TerrainData и назначаемые TerrainLayer. Сохраняются
высоты, alphamaps/покраска, количество и порядок слоёв, детали, деревья,
положение Terrain; его Collider получает копию того же TerrainData.
Меняются текстуры категорий Grass, Forest, Mud/Dirt/Soil, Gravel и повтор.
Подходящие плоские MeshRenderer с материалами земли получают копии URP/Lit.
Для читаемых планарных мешей повтор оценивается по горизонтальному размеру
и диапазону UV; при недоступных UV сохраняется прежний texture scale.
Произвольная UV-развёртка или повёрнутые UV требуют визуальной настройки.
SkinnedMeshRenderer, листва с alpha clip и прочие поверхности не выбираются.

**PBR.** Сначала используются карты существующих материалов, затем пары
текстур с одинаковым именем/папкой. Доступны color/normal/roughness/
smoothness/AO/height/metallic. Для data maps создаются временные читаемые
линейные копии; оригинальные importer settings не меняются. Собственный
маск размером до 1024×1024: R=metallic, G=AO, B=height, A=smoothness.
Roughness преобразуется как `1−roughness`. Нераспознанные packed ORM-карты
не угадываются. Отсутствующие карты не генерируются из цвета.

**Движения.** Копируются существующие player prefab, AnimatorController
и профиль. Заменяются только выбранные локомоционные клипы. Состояния,
переходы, параметры, маски, IK, камера и существующие действия сохраняются.
Не назначенные sprint/back/strafe/crouch остаются прежними; jump, death,
carry, wounded, interaction и flashlight не подменяются обычной ходьбой.
Новая модель Kevin Iglesias не добавляется в мир.

Для каждого заменяемого движения измеряются фактические контакты стоп
на Avatar героини. Новый темп учитывает отношение скоростей старого и
нового клипа, сохраняя текущую скорость игрового motor. Root motion
выключен, Animation Events убраны только из созданных копий. Неизмеримый
или несовместимый клип прерывает установку с сохранением исходного мира.
Затем повторно измеряются bounds нового набора поз через bind-pose skinning.
Скольжение стоп и качество переходов всё равно проверяются в Play.

Создаются отдельный сетевой реестр и player-варианты для копии мира;
protocol повышается при изменении движений. Для кооператива заново собери
**обе** сборки из нового мира через окно 28.

## Файлы и отчёты

`Assets/_Silence/Generated/ImportedAssets/<UTC>/`:

- `..._Assets.unity`, `installation.json`, отдельный NetworkPrefabs.asset;
- `Ground/Materials`, `Ground/Textures`, копии TerrainData и TerrainLayer;
- `PlayerN/Player.prefab`, ImportedMotion.controller / .asset, Clips;
- `PlayerN/imported-motion-report.json`: исходные клипы, роли, темп;
- `PlayerN/character-audit.json`: реальные замеры поз в пользовательском Unity.

`Library/Silence/ImportedAssetsValidation.txt` — ссылки на новые движения
и текстуры активного мира, а не только запись об установке.

## Проверки и пределы

264 Core-теста прошли, включая 42 новых случая распознавания ролей,
отличия обычной ходьбы от carry/wounded/turn, female/in-place, карт PBR
и корректировки темпа. Пять тестов точного полного установщика из ZIP
прошли на временных проектах, включая сохранность vendor-ресурсов,
мира и .meta, добавление файлов и откат при сбое копирования.

Три native-теста предоставлены для Unity Test Runner: фактический каталог
Kevin Iglesias, копирование TerrainData без изменения высот/покраски,
ссылки готового контроллера на Imported_Idle/Walk/Run. **Они не запускались.**
Unity Editor и импортированные пользователем ассеты находятся на Mac,
в облаке их нет. Страницы Asset Store из среды вернули proxy 403; их
содержимое не выдаётся за прочитанное. Код работает с реальными локальными
ресурсами после запуска окна 28; фактическое подключение на Mac, Unity API
компиляция, rendering, Play, качество движений и кооператив ещё не подтверждены.

Облачные результаты: `Docs/Validation/ImportedAssets050/`.
