# CS0136 в PlayerAnimationControllerBuilder — исправление 0.4.2

В `Build(Animator target, string output)` на строке 127 был цикл
`foreach (string target ...)`. C# запрещает такое повторное имя в дочерней
области метода. Переменная цикла и её обращения переименованы в
`destinationState`. Сам набор переходов Crouch/CrouchIdle не меняется.

Прежняя проверка только разбирала синтаксис и не могла обнаружить CS0136.
Теперь SourceChecks дополнительно запускает настоящий Roslyn compiler и
проверяет **CS0136, CS0128, CS0100**. Другие semantic diagnostics и привязка
к Unity API не считаются проверенными: Unity Editor/assemblies здесь нет.

Детектор сначала запущен на исходном файле 0.4.1: он нашёл **тот же конфликт
на строке 127** во всех семи вариантах preprocessor symbols. После переименования
проверка всех 146 C#-файлов в тех же вариантах не обнаружила этих конфликтов.
Восемь отдельных регрессионных случаев детектора прошли, включая воспроизведение
CS0136 при отсутствующей UnityEngine-сборке. Полный Editor/Play не запускались.

Логи: `Docs/Validation/ScopeFix042/before-fix.txt`, `after-fix.txt`,
`scope-regressions.txt`. Последовательность воспроизведения и исправления
зафиксирована, а не заменена заявлением об успешной компиляции всей игры.

Установка: скачать **SILENCE_HumanMotion_0.4.2.zip**, распаковать → остановить
Play → **SILENCE → 00 Update Sources From Folder** → выбрать распакованный
корень с Assets и LocalPackages → дождаться компиляции → **Console → Clear**.
Продолжить **25**. Уже импортированные клипы и игровой мир пересоздавать не нужно.
