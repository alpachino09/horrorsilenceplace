# Vesper в игровой сцене — пакет подключения

По проверке в `SilenceMonstr.blend` находились стандартный куб, камера, свет и две
пустые сцены Vesper. Геометрии, скелета и анимаций монстра в нём нет. Владелец явно
выбрал восстановление нашей **Vesper 0.2 с большой пастью и 104 клыками**.

В этой ветке уже находятся настоящие модели и карты, а не только генератор:

- `Assets/Creatures/SilencePredator/Models/Vesper_LOD0.fbx` — скелет и 22 клипа;
  `LOD1`/`LOD2` используют те же 55 деформирующих костей.
- `Textures` — 12 PNG 4096 × 4096: Skin, Armor, Tissue и Bone, по три карты.
- `ArtSource/VesperGame/Vesper_Game.blend` — восстановленный редактируемый исходник.
  Открывать его нужно из распакованного репозитория, сохраняя папки Assets/ArtSource:
  текстуры имеют относительные пути, внутрь `.blend` не упакованы.
- `VesperGamePresentation.cs` — движение скелета, слои дыхания/слуха, коррекция лап
  по поверхности и поворот шеи к **принятому звуку**, без получения позиций игроков.
- `VesperGameInstaller.cs` — установка, проверка и сборка через меню Unity.

## Самый короткий путь в Unity

1. На GitHub открой ветку **codex/monster-game-integration**, нажми **Code → Download ZIP**
   и распакуй архив. Для закрытого репозитория войди в свой GitHub.
2. Скопируй из архива **только файл** `Assets/_Silence/Editor/SilenceSourceUpdater.cs`
   в тот же путь своего Unity-проекта, заменив прежний файл. Дождись компиляции.
   Это обновляет загрузчик: он умеет копировать модели/PNG из Assets/Creatures.
3. **SILENCE → 00 Update Sources From Folder** → выбери корень распакованного архива,
   содержащий Assets и LocalPackages. Не выбирай свой Unity-проект. Исходники, FBX и
   PNG скопируются; существующие сцены, Generated и `.meta` сохраняются, старые файлы
   резервируются в Library/Silence/SourceBackups. Дождись импорта карт и компиляции.
4. Открой исходную игровую сцену **Campaign** (или другую сохранённую игровую сцену
   с одним HearingCreature) → **SILENCE → 18 Install Vesper in Game Scene**.
   Команда предназначена создать и открыть отдельную копию `Campaign_Vesper.unity`.
5. **SILENCE → 19 Validate Vesper Game Scene**, затем **Play** и Host/начало раунда.
   Отчёт проверки: `Library/Silence/VesperValidation.txt`.
6. Для кооператива: **SILENCE → 20 Build Vesper Host and Client**. Обе стороны нужно
   пересобрать из одной новой сцены. У неё сетевой протокол **4**, старые сборки не подходят.

Меню 17 относится к отдельной художественной демонстрации. Для замены в игре нужен **18**.
Если пакет multiplayer ещё не установлен из LocalPackages, сначала выполни прежний пункт 03.
При повторной установке используй исходную Campaign: уже созданная Vesper-сцена защищена
от повторного наложения ещё одной модели.

## Что изменено в анимациях

Добавлены GameWalk, GameRun и BreathGame; прежние 19 клипов сохранены. Походка имеет
разнесённые опорные фазы четырёх лап, перенос веса и сгибание пальцев. Во время переноса
лапы траектория сохраняет непрерывную скорость у перехода от опоры к взмаху.
В Blender опорные фазы измерены относительно неподвижного пола и движущегося тела.
Для Unity также исправлено направление граней оболочки головы, внутренней пасти
и зеркальных слуховых мембран на всех трёх LOD: в Blender двустороннее отображение
скрывало ошибку. Отдельная проверка подтверждает наружные/внутренние нормали головы.

В Unity создаётся один Generic Animator с тремя слоями: базовое движение/атака,
аддитивное дыхание груди и позвоночника, отдельная маска шеи/слуховых створок.
Скорость воспроизведения походки вычисляется по реальному перемещению и масштабу
импортированных костей. Дыхание и прислушивание имеют своё время воспроизведения.
Челюсть исключена из слуховой маски, поэтому атака и открытие слуховых створок не
подменяют друг друга. На неровном полу предусмотрен отдельный решатель лап; его
работу нужно проверить в настоящей сцене Unity.

Сервер отправляет только уже принятый слуховым ИИ звук и подтверждённую игровым
уроном атаку с временными метками. Клиентские анимации не наносят урон, не выбирают
цели и не двигают сетевой корень. Root motion выключен. Условия слышимости, баланс,
NavMesh-скорости и правила нанесения урона сохранены.

Звуки дыхания и шагов пока процедурные временные. Для качества кинематографического
звука нужны реальные записи и сведение. URP Lit также не повторяет Blender SSS автоматически.

## Проверено и что осталось

- Реальная повторная загрузка `.blend`, 22 клипа, 55 костей, четыре поверхности/три LOD,
  12 карт 4K, 104 клыка, нормализованные веса и повторный импорт трёх FBX.
- Измерения движущихся опорных лап и расширения/сжатия грудной клетки в Blender.
- .NET/NUnit: тесты ядра; Roslyn: синтаксис C# с пятью конфигурациями define.
  Эти проверки **не заменяют** Unity API binding, NGO ILPP и Play Mode.
- Реальные кадры и GIF в `Previews` получены в Blender, это не видеозапись Unity.

В облаке нет Unity Editor: `.unity`, `.prefab` и AnimatorController подготовлены
кодом, но здесь не создавались. Импорт в Unity 6000.6.7f1, протокол/ILPP, слои
Animator, контакт лап со ступенями, материалы, FPS на M1 и 2/4 сетевых процесса
ещё не проверены. Ультрареалистичный финал не заявляется достигнутым.
Точные отчёты лежат в `Docs/Validation/VesperGame`.
