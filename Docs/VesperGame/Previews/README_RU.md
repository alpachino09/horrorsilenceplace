# Предпросмотр из Blender

Это реальные рендеры восстановленной Vesper, не видеозапись из Unity.
GameWalk: 12 кадров одного цикла с неподвижной разметкой пола;
камера следует за движущимся телом. ListenStart: 8 кадров раскрытия слуховых створок.
BreathGame: четыре отдельных фазы дыхания; GIF намеренно редкий,
в исходном клипе 139 ключевых кадров.

front_culling_check.png проверяет видимость головы и пасти с прозрачной
обратной стороной граней. Это приближение отсечения граней, не проверка URP.
Материалы и освещение Blender не гарантируют такой же результат в игре.
