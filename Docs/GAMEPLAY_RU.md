# Игровой цикл 0.3.0

Написан большой блок игры по исходным документам и 126 ответам: слух существа, предметы,
ранения и лечение, прохождение семи глав, голосование, развязки и checkpoint. Это исходники
игровых систем с временным контентом. Полноценная художественно законченная игра на 4–6 часов
ещё не готова. Новые сцены и сетевые механики требуют выполнения в настоящем Unity.

Последнее указание владельца разрешает продолжать несколько направлений без ожидания его
возвращения. Поэтому разработка продолжена за пределами Sprint02. Исходный GDD и ответы
сохранены без изменений; предложенные тексты, параметры и развязки не объявлены утверждёнными.

## Самый короткий путь после сна

1. Скачай свежий ZIP этой ветки GitHub через **Code → Download ZIP** и распакуй.
2. В уже установленном Unity-проекте останови Play. Нажми **SILENCE → 00 Update Sources From Folder**,
   выбери распакованную папку, внутри которой находятся `Assets` и `LocalPackages`. Дождись компиляции.
   Если меню 00 ещё старое, сначала скопируй из ZIP только `SilenceSourceUpdater.cs`, как описано в README.
3. **SILENCE → 03 Install Multiplayer Package** — подключает обновлённый локальный пакет 0.3.0.
   Оставь официальный NGO **2.13.3** и установленный Transport **6.6.0**.
4. **SILENCE → 09 Generate Campaign Gameplay**, затем **11 Validate Campaign**.
   При красной ошибке остановись на ней: исходный текст ошибки нужен для исправления.
5. Открой `Assets/_Silence/Generated/Gameplay/Campaign.unity`, нажми **Play → Создать сессию → Начать раунд**.
   Для одного игрока достаточно Host. Ферма и сетевой мир прежних этапов сохраняются отдельно.
6. Для автоматической проверки останови Play и нажми **12 Run Solo Gameplay Checks**.
   Она сама запускает одиночный Host. Дождись строки `SILENCE Gameplay checks — Failures: …` (около минуты),
   затем останови Play. Отчёт: `Library/Silence/GameplayChecks.json`.

Для запуска вдвоём: **10 Build Campaign Host and Client**, затем **07 Launch Host and Client**.
Host создаёт сессию, Client подключается к `127.0.0.1` на том же компьютере или LAN IPv4 хоста.
Сначала соберите группу, затем Host начинает раунд. Меню **05** по-прежнему собирает старую
тестовую ферму; для новой кампании используй **10**. Передача через интернет/Steam пока отсутствует.

Повторная команда 09 сохраняет существующую кампанию. Если генерация прервалась, переименуй
папку `Gameplay` через Unity Project, сохранив её содержимое, и повтори 09. Не удаляй Generated
и `.meta` через Finder. Не устанавливай сторонний Simple Input вместо официального Input System.

## Управление новым блоком

- WASD/мышь, Shift — бег, Ctrl — приседание, Space — прыжок.
- E — взаимодействовать, F — фонарь, Esc — меню.
- ПКМ удерживать и двигать мышь горизонтально — вести дверь; медленно тише. E двигает её быстро.
- Tab — открыть/закрыть карманы и освободить курсор. Цифры 1–5 в игре применяют предмет;
  в открытых карманах выбери слот и нажми кнопку применения/выкладывания.
- G — отпустить переносимый объект/союзника, иначе выложить выбранный слот.
- Удержать и отпустить ЛКМ при переноске предмета — бросок; дольше до 1,2 с — сильнее.
- E на раненом союзнике: лечение при наличии лекарства, иначе переноска при свободных руках и месте.
  E на погибшем союзнике рядом: применить спасательный набор. Переносимый игрок может нажать G, чтобы освободиться.
- Одну последнюю батарейку система оставляет для радио до получения сигнала. Новые батарейки можно применить для фонаря.
- Рюкзак на ферме расширяет карманы до 5 мест без отдельного расходуемого слота. Это настраиваемое предложение из плана.

## Как устроены главы

Генератор создаёт **одну постоянную сетевую сцену Campaign.unity** с семью пространственно
разнесёнными локациями и семью отдельными NavMeshData. Переход переносит группу и существо
на следующую локацию; мир и NetworkManager сохраняют сетевые ID. Старые главы недоступны
через обычный маршрут; защита границ возвращает вышедшего за пределы текущей главы.
Это сознательный первый вариант переходов, а не реализация отдельной загрузки/выгрузки семи сцен.
Все локации пока остаются в памяти; дальняя отсечка камеры и туман не заменяют профилирование.

Каждая глава использует общую механику целей, но имеет собственные геометрию, поверхности,
запись и радиотекст. Геометрия, faceless creature, текстуры и синтетические звуки временные,
созданы кодом. Радиосообщения сейчас текстовые, без записанной речи. Никакие сторонние модели
или звуковые записи не скачивались. Предлагаемые тексты и три развязки редактируются в Chapter assets.

Checkpoint: `Application.persistentDataPath/silence-checkpoint-v1.json`, резервная копия `.bak`.
Сохраняется начало главы, сюжетные флаги, ёмкость и расходуемые предметы. Порядок игроков
соответствует порядку входа в текущую группу; Steam-идентификация не подключена. Это не сохранение
каждого перемещённого предмета посреди главы. После общего wipe восстанавливается начало текущей главы.
Меню 12 отключает запись сохранения на время своей проверки и не меняет существующий checkpoint.

## Проверки

В облаке: **92 NUnit-теста чистого C#-ядра**, 0 ошибок/пропусков. Проверены выносливость,
раны/лечение, звуковые профили, слуховая память, семь последовательных глав, развязки,
голосование/таймеры/отключения, инвентарь/рюкзак, микрофонная огибающая и лимит команд.
`gameplay-core.trx` — реальный результат .NET, он не является отчётом Unity.

Roslyn проверяет C# 9 в пяти наборах define; отдельный скрипт — имена Unity-компонентов,
сборки, Input Actions и сохранность оригинальных документов. Новые AI/Audio API сверены
с опубликованными исходниками UnityCsReference ветки 6000.6; NGO — с официальным 2.13.3.
Это **не связывание API в Unity и не запуск генератора**.

Меню 11 проверяет ассеты/ссылки/компоненты. Меню 12, если реально выполнено в Unity,
проверяет Host spawn, единственную камеру/слушатель, наличие навигации, слуховой ответ,
движение двери, перенос/бросок, лекарство, смерть/wipe, задания и переходы семи глав.
Оно вызывает часть доменных действий напрямую, отключает движение существа после проверки слуха
и не доказывает доступность каждого предмета пешком, баланс или сетевую передачу этих действий.

## Приёмка в Unity после импорта

1. 09 создаёт ассеты, 11 выдаёт `Failures: 0`; Console без красных ошибок. 12 выдаёт полный JSON
   с `completed: true`, всеми checks=true, без error. Сохрани реальный отчёт после выполнения.
2. Вручную пройти ферму: тихие шаги/стекло, E и медленная дверь, бросок железного предмета,
   отрыв от преследования, лекарство, батарейка, рюкзак, радио, документ и выход.
3. Два отдельных процесса: второй игрок шумит, Host видит реакцию существа; дверь и предмет
   совпадают у обоих; одновременный подбор не удваивает предмет, занятый объект не забирается вторым.
4. Ранение, лечение/перенос другим игроком, смерть/редкий набор и наблюдение. Нет двух камер/слушателей.
   Выход при переноске, отключение несущего игрока, общий wipe не оставляют замороженного персонажа.
5. Оба игрока голосуют по-разному; переход завершается один раз. Инвентарь, здоровье, фонари и глава
   совпадают после каждого перехода. Повторить с 4 процессами и со всем доступным числом игроков.
6. Закрыть сессию и продолжить с начала сохранённой главы; испорченный JSON не ломает загрузку.
7. Микрофон: не записывает до включения; отказ разрешения не мешает игре; mute и отключение
   прекращают игровое шумовое влияние. Записей голоса на диске и передачи PCM нет.
8. Profiler на M1 Pro: CPU/GPU/frame time, allocations, physics, NavMesh и сетевой трафик. FPS пока не обещан.
