# Свой хищник Vesper — воспроизводимый Blender-генератор

По последнему указанию владельца создаётся собственная модель. Fab / ASC Teuthisan и Tyrant
сейчас не используются. Код, геометрия и карты этой поставки созданы для SILENCE;
фильм служит анатомическим ориентиром, его модели/текстуры не извлекались.

Это **процедурный художественный первый проход, не принятый AAA-финал и не подтверждённый
фотореализм**. Реальные меши, риг, материалы, клипы и экспорт созданы; эстетика, авторская
ретопология, деформации в предельных позах и игровая интеграция ещё требуют доработки.

## Запуск в Blender на Mac

Если команда скачивания отвечает `HTTP Error 404`, сам генератор ещё не запускался.
Доступность raw-ссылки в облаке не подтверждает доступ с компьютера владельца:
публичная ссылка может не открываться для закрытого репозитория или при другом доступе к GitHub.
В этом случае используйте **локальный файл**, без `urllib` и запросов к GitHub:

1. Войдите в свой GitHub в браузере, откройте
   [create_predator.py](https://github.com/alpachino09/horrorsilenceplace/blob/codex/original-predator/Tools/OwnPredator/create_predator.py)
   и нажмите **Download raw file** (стрелка вниз над кодом).
   Сохраните файл `create_predator.py` в папку **Загрузки / Downloads**.
2. В Python Console Blender (Shift + F4) вставьте одной строкой:

```python
from pathlib import Path; exec(compile((Path.home() / "Downloads" / "create_predator.py").read_text(encoding="utf-8"), "create_predator.py", "exec"), {"__name__": "__main__"})
```

Это запускает тот же генератор с диска. Интернет для моделирования и экспорта не нужен.

Проверенные среды: Blender **4.3.2**, CPU, и Python-модуль **bpy 5.2.3** / Python 3.13 на Linux.
Исправленная версия полностью создана с картами 4096 в bpy 5.2.3 и прошла 97 проверок
повторного открытия/импорта (`Docs/Validation/OwnPredator/material-fix-roundtrip.json`).
По 21 дополнительной проверке узлов материалов/мира выполнены в обеих версиях.
До исправления полная генерация также выполнялась в 4.3.2 (`blender.json`) и 5.2.3 (`blender-5.2.json`).
Интерфейс приложения Blender 5.2 и macOS здесь не запускались.
Скрипт не требует платных сервисов и дополнительных пакетов: используется numpy,
входящий в Blender. Минимальная проверка версии в коде — 4.2; остальные версии не проверены.

Ошибка `AttributeError: 'NoneType' object has no attribute 'inputs'` в старой версии
возникала, если поиск английского имени `Principled BSDF` не находил узел. Исправленный
генератор выбирает шейдер/выход по `bl_idname`, создаёт отсутствующие узлы и связывает
их; тот же способ применяется к полу и фону. Язык и настройки перевода пользователя
не меняются. Проверки воспроизводят отсутствие/переименование узлов настоящего bpy,
включая русские имена; полноценный русский интерфейс macOS здесь не запускался.
Если старый файл уже скачан, замените его новым `create_predator.py` в Downloads.

1. Открой Blender. Нажми **Shift + F4**: откроется Python Console.
2. Вставь одной строкой:

```python
import urllib.request; exec(compile(urllib.request.urlopen("https://raw.githubusercontent.com/alpachino09/horrorsilenceplace/codex/original-predator/Tools/OwnPredator/create_predator.py", timeout=30).read().decode("utf-8"), "silence_predator.py", "exec"), {"__name__": "__main__"})
```

Консоль Blender использует **Python, не Bash**. Генерация синхронная: интерфейс может временно
не отвечать, пока строятся карты/меш и экспортируются takes.
3. Дождись завершения. В интерактивном запуске редактор переключится в 3D View с материалами.
   Rig скрыт в viewport для чистого вида; для редактирования костей включи его глаз в Outliner.
   Операции интерфейса на Mac здесь не проверены; сама генерация выполнена в background Blender.
4. Папка результата — **Рабочий стол → SilencePredator**. Внутри `SilencePredator.blend` и `Assets/Creatures/SilencePredator`.
   Если предыдущий `.blend` уже есть, новый запуск создаёт отдельную папку `Run_...`, сохраняя его.
5. Существующие сцены пользователя не удаляются. Создаётся отдельная сцена
   `SILENCE_Vesper_Original`; файл сохраняет и другие уже открытые сцены.

Для системного Terminal/Bash есть `Tools/OwnPredator/run_macos.sh`. Он ищет Blender.app в Applications,
скачивает наш генератор через HTTPS и запускает Blender. Это **не команда для Python Console**.

Запуск с настройками (для shell):

```bash
SILENCE_PREDATOR_OUTPUT=/path/to/result SILENCE_PREDATOR_TEXTURE_SIZE=4096 blender -b --python Tools/OwnPredator/create_predator.py
```

Разрешения карт: 512/1024/2048/4096. В облаке реально выполнен вариант **4096**, ранее 1024.
Явно заданный output предназначен для воспроизведения/перегенерации и может перезаписать
наши файлы в этом каталоге. Без переменной output ручной `.blend` защищён новой папкой Run.

## Что реально создано

- Связная кожа тела и четырёх конечностей: custom loft, объединение voxel remesh,
  сглаживание, анатомические складки и сухожилия. Источник высокой поверхности сохранён отдельно.
- Крупный плечевой пояс, узкая талия, вытянутый безглазый череп, сегментированная броня,
  три пальца на каждой лапе с отдельными костями и геометрическими когтями.
- Отдельная нижняя челюсть, нёбо/дно пасти/эластичные уголки, **76 отдельных зубов** до объединения
  в экспортный материал. Гуммы и зубы не рисуются одной текстурой.
- **Шесть независимо управляемых наружных слуховых створок** и шесть костей складчатых внутренних
  мембран. Открытие последовательное; кость челюсти отдельная. Масштаб всей головы не используется.
- **63 кости**, из них **55 деформирующих**, четыре IK-цепочки с pole controls.
  Вершинные веса нормализованы и ограничены четырьмя влияниями, включая LOD после decimate.
- Три комплекта **4K** PNG: Skin, Armor, Tissue — BaseColor, Normal и packed Mask
  (R metallic=0, G приближённый AO, B height, A smoothness). Bone — отдельный постоянный материал.
  Карты оригинальные процедурные, не фотографические сканы. Blender использует SSS для мягких тканей;
  стандартный URP Lit не воспроизводит этот SSS автоматически.
- Три реальные skinned FBX: около **85k / 36.6k / 10.2k треугольников**.
  IK вычисляется и запекается при FBX-экспорте. Управляющие кости в FBX не попадают.
- **19 отдельных клипов**: Idle, IdleBreathing, Walk, Stalk, Run, Sprint,
  ListenStart/Loop/End, Alert, TurnLeft/Right, AttackBite, AttackClaw, Lunge,
  Search, Investigate, Stunned, Recover. Это разные процедурные первые проходы,
  не обещание production-анимации. Контакты, скольжение, инерция и переходы требуют оценки.
- NLA хранит и экспортирует только наши take-ы; чужие Action не удаляются и не включаются.
- Редактируемый `.blend`, камеры, студийный свет, эталонная фигура высотой 1.75 м.

Death исключён осознанно: в текущем GDD игроки не убивают хищника. Stunned — только клип;
новая возможность оглушать монстра игровым кодом не добавлялась.

## Подготовка Unity — не выполненный импорт

Вместе с моделью генерируются `MonsterAnimationController.cs` и `Editor/SilencePredatorSetup.cs`.
Они также лежат в репозитории для просмотра. Используемый проект владельца — Unity 6000.6.7f1,
URP 17.6.0. Здесь нет Editor/лицензии, поэтому создание `.prefab`/`.unity` не заявляется выполненным.

После оценки модели можно скопировать с Рабочего стола **всю** папку
`Assets/Creatures/SilencePredator` в Assets/Creatures Unity-проекта.
Дождаться импорта → **SILENCE → 17 Create Original Predator Demo**. Команда предназначена создать:

- `Prefabs/Monster_Creature.prefab`: один Generic Animator, skinned LODGroup с общими костями,
  URP Lit материалы, основную капсулу/триггеры головы, груди и таза, точки Audio/VFX.
- `Demo/Monster_Demo.unity`: свет, камера, размерный ориентир и кнопки предпросмотра в Play.
- Animator Controller с 19 состояниями, переходами ListenStart→ListenLoop, выходом из атак/Recover,
  настройками loop/in-place для импортированных takes.

Существующие prefab/demo сохраняются при повторном запуске. Mono-контроллер — только презентация:
не ищет игроков, не наносит урон и не меняет сетевой root. Прямая интеграция новой модели в
HearingCreature/host-client пока не сделана. Для смешивания атаки челюстью и слуха в Unity ещё
нужен отдельный слой/mask: независимые кости уже есть, но один базовый Animator-слой их не смешивает.
Размер 2.6–3 м требует отдельной оценки проходимости существующих дверей и NavMesh; импорт
красивой модели не решает это автоматически.

## Реально выполненные проверки и незавершённые пункты

- В `Docs/Validation/OwnPredator/blender.json`: повторное открытие `.blend`, 19 actions,
  4 IK, 6 слуховых костей, три LOD/UV, конечность координат и поз, нормализация весов,
  разрешение 4K. Настоящий FBX повторно импортирован в Blender; проверены 55 костей/19 takes
  и выборочные деформированные поверхности с допуском 2.5 см. Это **не Unity-проверка**.
- C# Roslyn: проверка синтаксиса и define-конфигураций. Она не проверяет API binding/ILPP.
- Unity import/Generic Avatar, shader/материалы, prefab/demo, коллизии, NavMesh, 2/4 процесса,
  FPS на M1 Pro **не проверены**. Сами `.prefab`/`.unity` пока не созданы.
- Ручная скульптурная доводка, профессиональная ретопология/суставные петли,
  UV/tangent high-to-low bake, точная биомеханика/постановка лап, отсутствие всех пересечений,
  смешивание слуха/атак в Animator и художественный уровень AAA **не завершены**.

Исходный запрос сохранён в REQUEST_RU.md. Исходная архитектура/126 ответов и все прежние
runtime/gameplay-файлы сохраняются. Следующий шаг — оценить эту модель в Blender, доработать
силуэт/голову/поверхности и затем проверить Generic Rig/анимации в настоящем Unity.
