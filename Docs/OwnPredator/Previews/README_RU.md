# Рендеры настоящей модели Blender

Все изображения получены из сгенерированного `.blend` в Blender 4.3.2 Cycles CPU, 32 samples.
Это не фотографии, не скриншоты Unity и не подтверждение AAA-качества.
Свет студийный; у horror уменьшена мощность света/мира. Фигура scale имеет высоту 1.75 м.
Источник — оригинальные геометрия, карты и риг генератора Tools/OwnPredator/create_predator.py.
