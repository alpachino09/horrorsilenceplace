Добавлен код Sprint 02: сетевое лобби, серверное движение, общие предметы/двери и сборки Host/Client.
**Кооператив ещё требует запуска в Unity и проверки двух процессов.** В облаке пройдены

сначала верни **2.13.3** через Package Manager, затем обнови наш код по шагам ниже.
[Восстановление после ошибки](Docs/SPRINT02_RU.md#если-после-установки-270-появилась-ошибка-entityid--cs0619).

## Обновление существующего проекта — без потери сцен

1. Нажми **Code → Download ZIP** на странице этой ветки GitHub и распакуй архив.
2. Из архива скопируй **только** файл `Assets/_Silence/Editor/SilenceSourceUpdater.cs`
   в папку `Assets/_Silence/Editor` своего Unity-проекта. Дождись компиляции.
3. В Unity нажми **SILENCE → 00 Update Sources From Folder**. Выбери распакованную папку GitHub,
   внутри которой лежат `Assets` и `LocalPackages`. Дождись новой компиляции.
4. Нажми **SILENCE → 03 Install Multiplayer Package**. Дождись установки пакетов и компиляции.
5. Нажми **SILENCE → 04 Generate Network Farm**, затем **06 Validate Network Farm**.
6. Открой `Assets/_Silence/Generated/Sprint02/Farm_Network.unity` и нажми **Play**.
   Выбери **Создать сессию → Начать раунд → Продолжить** для проверки одного игрока.

Обновление сохраняет существующие `.meta`, сцены и `Generated`. Старый код резервируется
в `Library/Silence/SourceBackups`. Не заменяй целиком папку `_Silence` через Finder:
в ней находятся твои сгенерированные сцены и их ссылки.

Для проверки вдвоём используй **05 Build Host and Client** и затем **07 Launch Host and Client** (выбери каталог со сборками).
На Host нажми «Создать сессию», на Client — «Подключиться» (IP `127.0.0.1`), затем начни раунд на Host.
Проверку из двух настоящих процессов нельзя заменить двумя персонажами в одной сцене.
